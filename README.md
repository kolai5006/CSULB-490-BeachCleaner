# CSULB-490-BeachCleaner
Top Level Repository for Senior Design Project CSULB

to use this repository properly and to ensure that you have the right updates run this command here
please make sure that your directory is in this top level repo for all the repos to pull properly.

```
git submodule update --init
```

Alternatively, you can just cd into the submodules individually and just pull using

```
git pull
```

Once this command is run, the submodules/repos should be updated to the latest (WORKING) versions
